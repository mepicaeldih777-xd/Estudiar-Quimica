# Requirements: Chemical Education App

## Functional Requirements

### [FR1] Initial Knowledge Assessment
- [ ] System must generate a test to determine the student's starting knowledge.
- [ ] Results must initialize the student's competency level per topic.

### [FR2] Adaptive Learning
- [ ] System must select activities based on the student's performance.
- [ ] Activities should have multiple difficulty levels (1-5).
- [ ] Higher confidence in a topic triggers more complex exercises (e.g., balancing complex redox equations).

### [FR3] Hierarchical Content Visualization
- [ ] Topics must be displayed in a tree-like structure.
- [ ] Users can drill down from broad categories (Periodic Table) to specific sub-topics (Lanthanides).

### [FR4] Gamification
- [ ] Points/Rewards based on activity completion and performance.
- [ ] Interactive challenges and friendly competition elements.

### [FR5] Periodic Table Tool
- [ ] Interactive visualization of chemical elements.
- [ ] Learning modules for properties (Electronegativity, Atomic Radius, etc.).

## Non-Functional Requirements

### [NFR1] Design and UI
- [ ] Clean and minimalist style.
- [ ] Clear priority and status indicators (color-coded).
- [ ] Responsive design for personal daily use.

### [NFR2] Performance
- [ ] Fast loading of periodic table data and interactive games.
